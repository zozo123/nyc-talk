\begin{frame}{Who can stop an unwanted action?}
\textcolor{alarm}{Worker controls:} its code, workspace and requests.

\textcolor{acid}{Controller owns:} launch policy, service permissions, verification and publication.

\subline{Synthetic credentials and data. A loopback service. No live model or external target.}
\evidence
\note{We begin after an adversarial action has been chosen. This makes enforcement reproducible. Isolated mode uses Linux user, PID and mount namespaces through bubblewrap, with a separate network namespace where specified. The service and controller remain outside the worker. Reference mode does not establish those boundaries. Read the evidence label honestly.}
\end{frame}

\begin{frame}[fragile]{01 / It can read another project's data}
\begin{lstlisting}
request: GET /projects/other/private

runner credential     200 + synthetic fixture
task credential       403
task input            200
expired credential    403
\end{lstlisting}
\subline{The service honored the credential we supplied.}
\evidence
\note{The weak launcher passes a synthetic broad runner token into the child. It reads another project even though its task ID says parser-fix. The repaired launcher projects a task-scoped token. Repeat the identical forbidden request and the service refuses it. Then read task input successfully. Expiry and wrong-audience checks also run. Our local service uses an in-memory grant table rather than implementing OAuth.}
\end{frame}

\begin{frame}{Authority for this task}
\textcolor{acid}{Launch:} clean environment and closed extra descriptors.

\textcolor{acid}{Grant:} task resource, operation, audience and expiry.

\textcolor{acid}{Enforcement:} a service or broker outside the worker.

\subline{A stronger process boundary still needs narrower credentials.}
\note{Ask what the child inherits before asking what the model intends. A short-lived token retains all its permissions until expiry. Keep broad upstream credentials outside the worker and project only the required capability. This finite lab demonstrates service-side scope, audience and expiry decisions. References: Linux environ(7) and RFC 9700.}
\end{frame}

\begin{frame}[fragile]{02 / It can change another job's state}
\begin{lstlisting}
worker writes /shared/next-job.json

writable bind   host fixture changes
read-only bind  write denied; fixture unchanged
/output         patch remains writable
\end{lstlisting}
\subline{\mountscope}
\note{Display the mounts act with tools/present.py. Use a next-job queue fixture, separate from the verifier. This keeps filesystem and acceptance failures distinct. The attack is an ordinary write to a deliberately mounted path. In isolated mode the controller checks host bytes, resets the fixture, removes the prior output, and reruns with a read-only bind. Reference mode skips this entire integration experiment.}
\end{frame}

\begin{frame}{A report with a known recipient}
\textcolor{acid}{Worker:} requests one fixed report operation.

\textcolor{acid}{Broker:} constructs the body and selects the team account.

\textcolor{acid}{Checks:} rejects extra recipient, payload and URL fields.

\subline{\networkscope}
\note{The worker emits a request on stdout. The controller treats it as untrusted input, accepts one exact schema, and constructs the report from controller-owned fields. Isolated mode gives the worker a new network namespace and tests reachability of the host loopback service. Arbitrary report strings would reopen a data channel. This operation does not establish universal freedom from covert channels.}
\end{frame}

Five cases show this defect and repair; they do not prove complete parser correctness.}

\begin{frame}{Appendix / Limits of the evidence}
Deterministic scripts exercise chosen actions.

Namespace and mount checks require the isolated run.

Five parser cases establish one demonstrated repair.

Controller code, keys and decisions remain trusted.

\subline{No cgroup, kernel-exploit, covert-channel or universal security claim.}
\note{Do not imply we measured model susceptibility to prompt injection or proved the absence of all sandbox escapes. The controls address named failure paths. The network probe targets the fixture endpoint. The history anchor is ephemeral. Production hardening and broader adversarial analysis remain separate engineering work.}
