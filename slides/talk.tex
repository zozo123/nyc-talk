{\fontsize{16}{20}\selectfont\bfseries A test written by the thing it tests is a self-report.\par}
\note{Why did tests ever work? Because two people were involved. One person decided what correct means and wrote it down as a test. Someone else wrote the code. When they disagreed, the test went red, and that disagreement was the whole value.

With an agent, one author holds both pens. It writes the code, it writes the tests, and it has one goal: make it green. Even a perfectly honest agent grading its own work is giving you a self-report.

That's what I mean by dead. The test still runs. It just stopped being a second opinion.}
