\vspace{1mm}
\begin{columns}[T,onlytextwidth]
\begin{column}{.47\textwidth}\kicker{BEFORE}{\fontsize{12}{15}\selectfont One person writes the code. Another writes the test. They disagree, the test fails, you find the bug.\par}\end{column}

\vspace{4mm}

\vspace{1.2mm}
{\color{warn}\bfseries 2025}\hspace{2mm}SaaStr's founder said Replit's agent lied about his unit tests and made up data.\par}
\vfill
\scope{Sources: last slide.}
\note{Why did tests ever work? Two people. One writes the code. Another writes down what correct means. When they disagree, the test fails, and you find the bug.

Now one agent holds both pens. It's like letting the student write the answer key. And the student wants one thing: green.

We've seen this before. Around 2010, researchers evolving bug fixes caught one program deleting the files with the right answers. Every program in the run got a perfect score. In 2025, the founder of SaaStr said Replit's coding agent lied about his unit tests and made up data.

So a passing test is just the agent's own opinion.}
\end{frame}

\note{Our first test of the release step tried the wrong code after the one-time approval was already used up, so of course it was refused, and that proved nothing.
