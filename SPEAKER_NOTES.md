# Speaker notes

One factory path: freeze, execute, judge, gate.
The finding is a protected checker that still reads worker-controlled expected results.
Three surrounding grants are independent synthetic checks, not one exploit chain.
Workers are deterministic scripts. No model-driven exploitation claim.

## Slide 1

00:00 to 00:40. Small job: fix a parser, publish the report. The sandbox does not break. Ask what made the work eligible for release, and how much of that decision the agent could influence. Escaped means exceeded the task through granted interfaces.

## Slide 2

00:40 to 02:00. Walk the factory: untrusted dev VM, controller collection into immutable storage, fresh accept VM that only runs frozen candidate bytes, controller-owned expected results, gate, publish from the frozen object. A second VM is not independence if judgment still reads worker inputs. Five cases prove five cases.

## Slide 3

02:00 to 05:00. This is the finding. Checker file hash unchanged. Worker wrote expected.json to match the bug. Protected executable, worker-controlled criteria. Independent judge still fails empty fields. A PASS file the controller believes is a deliberate detector, not a surprise. Not a kernel escape.

## Slide 4

05:00 to 06:30. Honest comparison can still release the wrong file if publication reads the live path. Two hashes of a mutable path are not a freeze. Freeze is collect, store, digest, evaluate that object, publish that object. Stale approval and replay denied. Nonces persist across controller restart.

## Slide 5

06:30 to 08:30. Surrounding map from the accepted abstract. Identity, files, data release. Each unwanted action, repair, and legitimate operation. Namespaces held. The grant did the damage. Do not turn this into a four-step attack story.

## Slide 6

08:30 to 11:00. Move every decision input off the worker. Accept VM gets no credential that can rewrite the checker. Incomplete evidence is no approval, not a defense. Gate binds artifact, run, verifier bundle, expected results, policy, environment, decision, nonce. History detects rewrite. History does not authorize.

## Slide 7

11:00 to 12:20. Good parser published. Buggy parser rejected. PASS file ignored. Worker expected.json ignored. Swap after freeze denied. Return to the opening input: it now rejects. The useful job completes.

## Slide 8

12:20 to 13:20. Four questions in act order. Include snapshots, templates, expected results, collection path, and harness green checks under files and approval. Name the refusing component. Test the happy path afterward.

## Slide 9

13:20 to 14:00. We built this workflow. The sandbox held. The decision still depended on the worker until judgment moved off its evidence. Ask who gave the process the authority. Stop. Keep one minute of margin. No extra section.

Appendix only. Not a kernel, cgroup, or covert-channel claim. History anchor is a controller file. Writable-checker and PASS-file variants are deliberate detectors. Prior art covers in-sandbox graders; the miss is trusting worker-controlled inputs after protecting the checker file.
